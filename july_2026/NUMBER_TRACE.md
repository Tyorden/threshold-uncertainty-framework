# NUMBER_TRACE — every number in draft.tex, traced to a results file

Rule of the house: a number may appear in the paper only if it appears in (or
is directly computable from) a results file in one of the seven verified
source folders (all re-verified CONFIRMED, byte-identical, 2026-07-09; see
each folder's `notes/VERIFICATION_FABLE.md`). Paths below are relative to the directory that contains the source
folders (in the public release: the four application repositories cloned
as siblings of this repository, using their original folder names).

The cross-program Table 1 is generated by
`FLAGSHIP_threshold_methods/scripts/build_summary_table.py`, which reads the
files below and asserts every value before writing
`FLAGSHIP_threshold_methods/results/cross_program_summary.csv`.

## Statutory / documentary constants (not folder numbers)

Rule constants (50/80/120 percent MFI cuts; 20 percent QCT cap; 2-of-3
vintages; IMU <= 62.0 and subscore caps; Title I >6,500 / >15 percent;
>=20 percent x K periods; 140 percent LAUS ratio; CI width > 20 pts or >
1.2x) come from the statutes, regulations, and notices cited in the
bibliography and were each verified against primary sources in the source
folders' notes (e.g. `QCT_lihtc/data/FR_2025-19007_qct_dda_2026.txt` on
disk confirms 90 FR 46904-46910). Verbatim quotes in the draft
(Census user note 2022-04, BLS Handbook of Methods LAUS presentation page,
HUD Notice CPD-24-04, HUD PD&R LMISD alternative-data report p. on
precision) were web-verified against the primary documents on 2026-07-10;
the LMISD report quote was checked against the PDF text itself
(huduser.gov/portal/sites/default/files/pdf/LMISD-AlternativeData.pdf).
